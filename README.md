## แอปนี้ช่วยอะไร

- **หากิจกรรมในมอได้ในที่เดียว** หน้า "วันนี้" รวมกิจกรรมทั้งหมด ค้นหา กรองหมวด/ช่วงเวลา และกดหัวใจบันทึกไว้ดูทีหลัง
- **ชั่วโมงกิจกรรมไม่ต้องจดเอง** ลงทะเบียน → ส่งรูปหลักฐานการเข้าร่วม → เจ้าหน้าที่ตรวจผ่าน → ชั่วโมงขึ้นในโปรไฟล์

## บทบาท

บัญชีละ 1 บทบาท เลือกตอนสมัคร · server ตรวจสิทธิ์ทุกคำขอ

| | นักศึกษา | เจ้าหน้าที่กิจกรรม |
|---|---|---|
| กิจกรรม | ลงทะเบียน · ส่งหลักฐาน · ตั้งเตือน · ดูชั่วโมง | สร้างกิจกรรม · ตรวจหลักฐาน (ผ่าน/ไม่ผ่าน) · ไม่รับการลงทะเบียน · ยกเลิกกิจกรรม · ประกาศถึงผู้ลงทะเบียน |

แท็บ: วันนี้ · บันทึกไว้ (เจ้าหน้าที่: จัดการ) · แผนที่ · แจ้งเตือน · ฉัน

แจ้งเตือนทุกอันเกิดจากการกระทำของอีกฝั่ง (ไม่มีปุ่มทดสอบ) · แจ้งเตือนเด้งตอนเปิดแอป · เว็บใช้แจ้งเตือนของเบราว์เซอร์

## ติดตั้งและรัน

ต้องมี Node.js LTS และแอป **Expo Go** บนมือถือ

```bash
npm install
npm start          # เปิด API (พอร์ต 3001) + Expo พร้อมกัน แล้วสแกน QR ด้วย Expo Go
npm run web        # เปิดบนเว็บ (จอคอมแสดงเป็นกรอบมือถือ)
npm run reset-live # ล้างข้อมูลกลับเป็นข้อมูลตัวอย่างขณะ server เปิดอยู่ (ทุกเครื่อง login ใหม่)
npm run reset-data # แบบเดียวกันแต่ต้องปิด server ก่อน
```

มือถือต้องต่อ Wi-Fi วงเดียวกับคอม ถ้าไม่ได้อยู่วงเดียวกัน (เช่น ตอนนำเสนอ) ใช้ tunnel:

```bash
npm run present    # เหมือน npm start แต่เปิดผ่าน tunnel ใช้เน็ตไหนก็ได้ (ต้องมี @expo/ngrok แบบ global)
npm run qr         # (อีกหน้าต่าง) สร้าง QR สำหรับ Expo Go และเว็บ ลง notes/qr/
```

ผ่าน tunnel แอปเรียก API ที่ `https://<tunnel>/api` ซึ่ง `metro.config.js` ส่งต่อไปยังพอร์ต 3001 · ที่อยู่ tunnel เดิมทุกครั้งตราบใดที่ไม่ลบโฟลเดอร์ `.expo`

## โครงสร้าง

```
server/          API (Node ล้วน) บัญชี กิจกรรม กล่องแจ้งเตือน · ข้อมูลเก็บใน server/.data
src/app/         หน้าจอ (Expo Router)
src/components/  UI ที่ใช้ซ้ำ (การ์ด, รายการกิจกรรม+ตัวกรอง, กล้อง, แผนที่, วงล้อเลือกเวลา)
src/state/       Context (session, กิจกรรม, บันทึกไว้, การลงทะเบียน, แจ้งเตือน)
src/services/    เรียก API และอุปกรณ์ (ตำแหน่ง, รูป, แจ้งเตือน)
src/lib/         logic ล้วนที่ทดสอบได้
src/data/        ข้อมูลร่วมแอปกับ server (อาคารในวิทยาเขต, สาขาคณะสหวิทยาการ)
__tests__/       ชุดทดสอบ
```

## เนื้อหาสัปดาห์ 1–14 ในแอป

ดูในแอปได้ที่แท็บ "ฉัน" → "เนื้อหาสัปดาห์ 1–14" เช่น Router (แท็บตามบทบาท), Forms (ฟอร์มลงทะเบียน/สร้างกิจกรรม), REST API, Offline (SQLite คิวส่งตอนไม่มีเน็ต),
Auth (SecureStore, ล็อกเดารหัส), Camera, Location/Maps (ชื่ออาคารจริงบนแผนที่ + นำทาง), Notifications, Testing, Build (EAS)

## ข้อจำกัด

- ข้อมูลเก็บเป็นไฟล์ JSON และเชื่อมต่อผ่าน HTTP ในวง Wi-Fi เหมาะกับการทดลอง ใช้จริงต้องเปลี่ยนเป็นฐานข้อมูล + HTTPS
- ใครก็สมัครเป็นเจ้าหน้าที่ได้ ใช้จริงควรให้หน่วยงานอนุมัติ · ยังไม่มี "ลืมรหัสผ่าน"
- Android ใน Expo Go ไม่รองรับ push จาก server แจ้งเตือนเด้งได้ตอนแอปยังเปิดหรืออยู่เบื้องหลัง
