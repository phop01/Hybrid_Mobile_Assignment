## 2 บทบาท (เจ้าหน้าที่แยกตามหน่วยงาน)

แต่ละบทบาททำได้เฉพาะงานของตัวเอง ตรงกับการทำงานจริงในมหาวิทยาลัย และ server ตรวจสิทธิ์ทุกครั้ง (ทำนอกหน้าที่ได้ 403)

**บัญชีละ 1 บทบาท** (นักศึกษา / เจ้าหน้าที่กิจกรรม / เจ้าหน้าที่อาคาร เลือกตอนสมัคร) แท็บ เมนู และสิทธิ์เปลี่ยนตามบทบาท · หน้าเข้าสู่ระบบมีปุ่มบัญชีตัวอย่างบทบาทละ 1 ปุ่ม แตะแล้วเติมรหัสให้ · กฎ "ของตัวเอง" เช่น รับเรื่องซ่อมที่ตัวเองแจ้งไม่ได้ ยืนยันงานได้เฉพาะผู้แจ้ง

|                                 | นักศึกษา                                                                     | เจ้าหน้าที่ **งานกิจกรรม**                                     | เจ้าหน้าที่ **อาคารสถานที่**                                                                       |
| ------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| กิจกรรม / จิตอาสา               | ลงทะเบียน · ส่งหลักฐานการเข้าร่วม (รูป, แนบเพิ่มได้) · ได้ชั่วโมง          | สร้างกิจกรรม · ดูรายชื่อ · ตรวจหลักฐาน · ประกาศถึงผู้ลงทะเบียน | – (ไม่เห็นแท็บกิจกรรม)                                                                             |
| แจ้งซ่อม                        | แจ้ง (ฟอร์ม 3 ขั้น) · "เจอเหมือนกัน" · ยืนยันผล                              | แจ้งได้เหมือนคนทั่วไป                                          | คิวงานตามความเร่งด่วน · รับเรื่อง + นัด · ปิดงาน (แนบรูปหลังซ่อมได้ ไม่บังคับ) · ปฏิเสธพร้อมเหตุผล |

| นำทาง (แอปแผนที่) + ดูระยะในแอป | ✓ (ไปกิจกรรม)                                                                | ✓                                                              | ✓ (ไปจุดซ่อม)                                                                                      |

## แจ้งเตือน: ทุกอันเกิดจากเหตุการณ์จริง ไม่มีปุ่มทดสอบ

| ใครได้                               | เมื่อไร                                                                                  |
| ------------------------------------ | ---------------------------------------------------------------------------------------- |
| ผู้แจ้งซ่อม + คนที่กด "เจอเหมือนกัน" | เจ้าหน้าที่รับเรื่อง / นัดเวลา / ซ่อมเสร็จ / ปฏิเสธ                                      |
| เจ้าหน้าที่อาคารสถานที่              | มีเรื่องแจ้งซ่อมใหม่ · ผู้แจ้งบอกว่ายังไม่เรียบร้อย                                      |
| เจ้าหน้าที่งานกิจกรรม                | มีหลักฐานการเข้าร่วมรอตรวจ                                                               |
| ผู้ลงทะเบียนกิจกรรม                  | ผู้จัดส่งประกาศถึงผู้ลงทะเบียน · ผลตรวจหลักฐาน (ผ่าน/ไม่ผ่าน)                            |
| ทุกคน                                | เจ้าหน้าที่ส่งประกาศ                                                                     |
| ผู้แจ้งซ่อม / ผู้ลงทะเบียน           | 1 ชม. ก่อนเวลานัดซ่อม · ก่อนกิจกรรมตามเวลาที่เลือก (ตั้งจากเวลาในข้อมูล ใช้ได้แม้ปิดแอป) |

วิธีทำงาน: การกระทำของอีกฝั่ง → server ใส่ **กล่องแจ้งเตือน** ของคนที่เกี่ยวข้อง และ **ส่ง push ผ่าน Expo Push Service** → iPhone เด้งแม้ปิดแอป/ล็อกจอ
ขณะเปิดแอปอยู่ แอปยัง poll `GET /me/inbox` ทุก 8 วินาทีเพื่ออัปเดตรายการ (เครื่องที่รับ push ไม่ได้ เช่น Android ใน Expo Go ใช้การเด้งจากการ poll แทน)
แตะแล้วเปิดหน้าที่ถูกต้องได้ทั้งตอนแอปเปิดอยู่ / อยู่เบื้องหลัง / ปิดไปแล้ว
**ต้องตั้งค่าครั้งแรก:** `npx eas-cli@latest login` แล้ว `npx eas-cli@latest init` (ใส่ projectId ลง app.json) และในแอปกด "เปิดแจ้งเตือน" ที่แท็บแจ้งเตือน · คอมที่รัน server ต้องต่อเน็ต

## แผนที่วิทยาเขต

แผนที่พื้นฐาน (Apple Maps / OpenStreetMap) ไม่มีชื่ออาคารในวิทยาเขต แอปจึงวาดป้ายชื่ออาคารเองจาก `src/data/campus-places.json`
(อ้างอิงแผนผัง KKU NKC MAP ของวิทยาเขต จับคู่กับรูปอาคาร/สระ/สนามใน OpenStreetMap เพื่อได้พิกัดจริง)

- ป้ายชื่ออาคารบนทุกแผนที่ · แตะป้ายตอนปักหมุด = เลือกอาคารนั้น
- ฟอร์มแจ้งเรื่อง: ปุ่มลัดเลือกอาคาร, หา GPS แล้วเติมชื่ออาคารที่ใกล้ที่สุด, พิมพ์รหัสห้อง `NK2217` แล้วแอปบอกว่าเป็น อครเก่า ชั้น 2 (NK1 = สำนักงานบริหาร, NK2 = อครเก่า, NK6 = อครใหม่)
- แก้ชื่อ/ย้ายตำแหน่งอาคาร: แก้ไฟล์ JSON ไฟล์เดียว แอปและ server (ข้อมูลตัวอย่าง) ใช้ไฟล์เดียวกัน
- **ให้หมุดตรงกับ Google Maps:** เปิด Google Maps → แตะอาคารให้ขึ้นชื่อ → แชร์ → คัดลอกลิงก์ → `npm run place -- "<ลิงก์>" <id อาคาร>` สคริปต์อ่านพิกัดหมุดจากลิงก์ (`!3d…!4d…`) แล้วแก้ไฟล์ให้ (ไม่ใส่ id = พิมพ์บรรทัด JSON ไว้เพิ่มอาคารใหม่) · ไม่ได้ดึงข้อมูลแผนที่ของ Google มาทั้งก้อน

## ความปลอดภัยและข้อมูลส่วนตัว

- รหัสผ่านเก็บเป็น scrypt + salt · login ผิด 5 ครั้งล็อก 60 วินาที · ข้อความ error เหมือนกันไม่บอกว่ารหัสไหนมีอยู่
- token: มือถือเก็บใน SecureStore, เว็บเก็บใน sessionStorage · server เก็บเฉพาะ **hash** ของ token (ไฟล์ข้อมูลหลุดก็ใช้เข้าระบบไม่ได้) · logout แล้ว token ใช้ไม่ได้ทันที
- server ตรวจบทบาท + หน่วยงานเจ้าหน้าที่ (403) และสถานะ (409) ทุก request ไม่พึ่งการซ่อนปุ่มในแอป · API ไม่ส่งรหัสผ่าน, idempotency key, รายชื่อคนที่กด "เจอเหมือนกัน" ออกไป
- แอปใช้ตำแหน่งเฉพาะตอนส่งหลักฐาน ปักหมุดแจ้งซ่อม และดูเส้นทาง (ไม่ติดตามเบื้องหลัง) · server เก็บแค่พิกัดตอนส่งหลักฐาน/แจ้งซ่อม
- จำกัดการแจ้งเรื่อง 5 เรื่องต่อ 10 นาทีต่อคน กันสแปมแจ้งเตือน
- หลักฐานการเข้าร่วมไม่บังคับตำแหน่ง/เวลา แต่บันทึกระยะจากจุดงานและเวลาถ่ายไว้ให้เจ้าหน้าที่ใช้ประกอบการตรวจ
- รูปตรวจว่าเป็น JPEG จริงและไม่เกิน 3 MB · payload แจ้งเตือนมีแค่ประเภท + ID · ข้อความจากผู้ใช้บนแผนที่เว็บถูก escape

## ข้อจำกัดที่รู้อยู่ (known issues)

- **ถ้าใช้งานจริงต้องทำเพิ่ม:** ใช้ HTTPS (ตอนนี้เป็น HTTP บน Wi-Fi วงเดียวกัน) · ลบบัญชีตัวอย่างใน `server/seed.mjs` · บทบาทเจ้าหน้าที่ควรให้หน่วยงานอนุมัติ (ตอนนี้เลือกเองตอนสมัคร) · รูปใน `/uploads` เปิดได้ถ้ารู้ URL (ชื่อไฟล์เป็น UUID เดาไม่ได้ ใช้จริงควรเป็น signed URL) · สมัครด้วยรหัสนักศึกษาใดก็ได้ ยังไม่ยืนยันตัวตนกับระบบมหาวิทยาลัย · ชื่อเรื่องแสดงบนหน้าจอล็อกเมื่อมีแจ้งเตือน

- แจ้งเตือนมาจากการ poll ขณะเปิดแอป (Expo Go ไม่มี push server) ถ้าปิดแอปไปนาน จะเห็นเรื่องใหม่ทันทีที่เปิดแอป · เตือนก่อนนัดซ่อม/กิจกรรมใช้ได้แม้ปิดแอป เพราะตั้งเวลาไว้ในเครื่อง
- เว็บไม่มีแจ้งเตือนของระบบ จึงแสดงเป็นแถบด้านบนของแอปแทน
- ข้อมูลเก็บเป็นไฟล์ JSON ใน `server/.data` เหมาะกับการนำเสนอ/ทดลองใช้ ถ้าใช้จริงต้องเปลี่ยนเป็นฐานข้อมูล
