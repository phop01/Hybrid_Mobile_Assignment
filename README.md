## แอปนี้ช่วยอะไร

- **ประกาศสำคัญไม่จมในแชต** เจ้าหน้าที่ส่งประกาศ (แนบโปสเตอร์ได้) ทุกคนได้แจ้งเตือน และประกาศค้างบนหน้า "วันนี้" จนหมดเวลา
- **แจ้งซ่อมแล้วรู้ความคืบหน้า** ถ่ายรูป + ปักหมุด → เจ้าหน้าที่รับเรื่องและนัดเวลา → ซ่อมเสร็จ → ผู้แจ้งยืนยัน ได้แจ้งเตือนทุกขั้น
  เรื่องซ้ำในรัศมี 50 ม. กด "เจอเหมือนกัน" แทนการแจ้งใหม่
- **ชั่วโมงกิจกรรมไม่ต้องจดเอง** ลงทะเบียน → ส่งรูปหลักฐานการเข้าร่วม → เจ้าหน้าที่ตรวจผ่าน → ชั่วโมงขึ้นในโปรไฟล์

## ติดตั้งและรัน

ต้องมี Node.js LTS และแอป **Expo Go** บนมือถือ

```bash
npm install
npm start          # เปิด API (พอร์ต 3001) + Expo พร้อมกัน แล้วสแกน QR ด้วย Expo Go
npm run web        # เปิดบนเว็บ (จอคอมแสดงเป็นกรอบมือถือ)
npm run reset-data # ล้างข้อมูลกลับเป็นข้อมูลตัวอย่าง (ปิด server ก่อน)
```

มือถือต้องต่อ Wi-Fi วงเดียวกับคอม

## โครงสร้าง

```
server/          API (Node ล้วน) บัญชี กิจกรรม แจ้งซ่อม ประกาศ กล่องแจ้งเตือน · ข้อมูลเก็บใน server/.data
src/app/         หน้าจอ (Expo Router)
src/components/  UI ที่ใช้ซ้ำ (การ์ด, กล้อง, แผนที่, วงล้อเลือกเวลา)
src/state/       Context (session, กิจกรรม, เรื่องแจ้ง, แจ้งเตือน)
src/services/    เรียก API และอุปกรณ์ (ตำแหน่ง, รูป, แจ้งเตือน)
src/lib/         logic ล้วนที่ทดสอบได้
__tests__/       ชุดทดสอบ
```

## ข้อจำกัด

- ข้อมูลเก็บเป็นไฟล์ JSON และเชื่อมต่อผ่าน HTTP ในวง Wi-Fi เหมาะกับการทดลอง ใช้จริงต้องเปลี่ยนเป็นฐานข้อมูล + HTTPS
- ใครก็สมัครเป็นเจ้าหน้าที่ได้ ใช้จริงควรให้หน่วยงานอนุมัติ · ยังไม่มี "ลืมรหัสผ่าน"
- Android ใน Expo Go ไม่รองรับ push จาก server แจ้งเตือนเด้งได้ตอนแอปยังเปิดหรืออยู่เบื้องหลัง
