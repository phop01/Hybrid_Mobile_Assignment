### Bug ที่เจอระหว่างทดสอบ

- **แนบรูปบนเว็บไม่ได้ทุกฟอร์ม ("source height is zero"):** `preparePhotoForUpload` เรียก `resize({ width: 960, height: null })` แต่ expo-image-manipulator บนเว็บตีความ `null` เป็นความสูง 0 → แก้เป็น `resize({ width: 960 })` (ให้คำนวณสัดส่วนเอง) ยืนยันด้วยการเลือกโปสเตอร์ในฟอร์มส่งประกาศบนเว็บ
- **login แล้วไม่กลับไปฟอร์มลงทะเบียน (เว็บ):** root layout ตรวจจังหวะ anonymous → authenticated แล้ว `router.push` ด้วย setTimeout 0 แต่บนเว็บ effect รอบแรกหลัง login เห็นสถานะเป็น authenticated อยู่แล้ว และ push ก่อนหน้า login ถูกปิดทำให้ Stack ย้อนกลับ → แก้ `src/app/_layout.tsx` ให้ใช้ `usePathname()` แล้วพาไปหน้าที่จำไว้เมื่อ login แล้วและไม่อยู่หน้า login/register ยืนยันด้วยการทดสอบบนเว็บข้อ 15
- **แจ้งเตือนไม่มาบนเว็บเมื่อแท็บไม่ได้อยู่ด้านหน้า:** กล่องแจ้งเตือน poll เฉพาะตอน `AppState === 'active'` แต่บนเว็บแท็บที่ไม่ได้ดูอยู่มีสถานะ `background` ทำให้สาธิตสองบทบาทในสองแท็บไม่ได้ → แก้ให้เงื่อนไขนี้ใช้เฉพาะมือถือ (`inbox-context.tsx`) ยืนยันด้วยการทดสอบบนเว็บข้อ 4
- **ช่องรูปว่างสูงเกินบนจอกว้าง:** กล่อง 4:3 เต็มความกว้าง 960px ดันปุ่มหลุดจอ → กล่องว่างสูง 140 และรูปสูงไม่เกิน 360

## ขั้นตอนสาธิต (วันสอบ Final)

1. **ค้นหา:** แท็บกิจกรรม → พิมพ์ค้นหา / กรองประเภท → กด ☆ บันทึกไว้ (ปิดแอปแล้วเปิดใหม่ยังอยู่)
2. **Login:** กดลงทะเบียน → ระบบพาไป Login แล้วกลับมาที่ฟอร์มต่อ
3. **ลงทะเบียน:** ลองส่งฟอร์มที่กรอกผิดเพื่อดู validation → ส่งสำเร็จ → ตั้งแจ้งเตือน
4. **แจ้งเตือน:** เลือกเวลาเตือน (1 วัน / 1 ชม. / ล่วงหน้า 30 นาที / นับถอยหลังจากตอนนี้เป็นวินาที) → ตั้งแจ้งเตือน; ผู้จัดส่งประกาศจากเว็บ → มือถือเด้ง → แตะแล้วเปิดหน้ากิจกรรม
5. **ส่งหลักฐาน:** หน้าการลงทะเบียน → การ์ด "หลักฐานการเข้าร่วม" → ถ่ายรูป/เลือกจากคลัง → ส่ง → สถานะ "รอตรวจ" (บันทึกระยะจากจุดงานไว้ให้เจ้าหน้าที่ดู)
6. **แนบรูปเพิ่ม:** หลังส่งแล้วกด "ถ่ายรูปเพิ่ม" ได้อีก 5 รูป
7. **ใบเซ็นชื่อกระดาษ:** กิจกรรม "หาดสีดา" → ถ่ายรูปใบเซ็นชื่อ → สถานะ "รอตรวจ"
8. **ผู้จัดตรวจ (อีกเครื่อง/เว็บ):** login `1000000001` → แท็บจัดการ → เลือกกิจกรรม → กด "ไม่ผ่าน" เลือกเหตุผล → นักศึกษาได้แจ้งเตือนพร้อมเหตุผล → ส่งใหม่ → ผู้จัดกด "ผ่าน" → นักศึกษาได้แจ้งเตือน + ชั่วโมงเพิ่มในโปรไฟล์
9. **ผู้จัดสร้างกิจกรรม:** แท็บจัดการ → สร้างกิจกรรมใหม่ → ลองส่งเปล่าดู validation → ปักหมุด → สร้าง → นักศึกษาเห็นกิจกรรมใหม่ในรายการ
10. **ออฟไลน์:** เปิดโหมดเครื่องบิน → รายการกิจกรรมและ "ของฉัน" ยังเปิดได้พร้อมแถบออฟไลน์ → เช็กอินแล้วเก็บเข้าคิว → ปิดโหมดเครื่องบิน → ส่งให้อัตโนมัติ
11. **Logout:** โปรไฟล์ → ออกจากระบบ (ล้าง token, cache และการแจ้งเตือน)

ปุ่ม "โหมดสาธิต" แสดงเฉพาะตอนรันแบบพัฒนา (`__DEV__`) และ server ต้องเปิด demo mode (ค่าเริ่มต้น)

## ถ้าเชื่อมต่อ API ไม่ได้

1. เปิด `http://<IP-คอมพิวเตอร์>:3001/health` ในเบราว์เซอร์ของมือถือ ต้องเห็น `{"ok":true,...}`
2. ถ้าเปิดไม่ได้ ให้อนุญาต Node.js ใน Windows Firewall (Private network) สำหรับพอร์ต 3001
3. ไม่รองรับโหมด `--tunnel` เพราะ API อยู่ในเครื่อง ถ้าจำเป็นให้สร้างไฟล์ `.env` แล้วใส่ `EXPO_PUBLIC_API_URL=http://<IP>:3001`
4. ข้อมูลใน server เก็บที่ `server/.data/` ลบโฟลเดอร์นี้เพื่อเริ่มใหม่

## ข้อจำกัดที่ทราบ

- **การแจ้งเตือนใช้ได้บนมือถือเท่านั้น** เว็บไม่รองรับ local notification (แอปแสดงข้อความแทนปุ่ม)
- **กล้องและตำแหน่งบนเว็บ** ใช้ได้เมื่อเปิดผ่าน `localhost` หรือ HTTPS เท่านั้น (ข้อกำหนดของเบราว์เซอร์)
  การเปิดเว็บจากมือถือผ่าน `http://<IP>` จะใช้กล้อง/ตำแหน่งไม่ได้ ให้ใช้ Expo Go แทน
- **บนเว็บ** token เก็บใน `sessionStorage` (ปิดแท็บแล้วต้อง login ใหม่) และใช้ AsyncStorage แทน SQLite
- server เป็น mock สำหรับการเรียน เก็บข้อมูลเป็นไฟล์ JSON ไม่ได้ออกแบบสำหรับผู้ใช้จริงจำนวนมาก
