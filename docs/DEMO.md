# สคริปต์นำเสนอวันสอบ (6–8 นาที) + ภาพประกอบแต่ละสัปดาห์

## เตรียมก่อนเข้าห้อง

1. `npm run reset-data` แล้ว `npm start`
2. **มือถือ (นักศึกษา):** Expo Go → หน้าเข้าสู่ระบบแตะปุ่ม "นักศึกษา" (`6609876543` / `campus1234`) → แท็บ "แจ้งเตือน" กด **"เปิดแจ้งเตือน"** → อนุญาต → iPhone ต้องขึ้น "แจ้งเตือนเด้งได้แม้ปิดแอปหรือล็อกจอ" (ถ้าขึ้น "เฉพาะตอนเปิดแอป" = ยังไม่ได้ `eas init` หรือไม่มีเน็ต) · Android ขึ้น "เด้งได้แม้ออกไปใช้แอปอื่น" · ทดสอบ: ออกจากแอป → เว็บเจ้าหน้าที่ส่งประกาศ → มือถือต้องเด้ง
3. **เว็บบนคอม แท็บที่ 1 (เจ้าหน้าที่อาคารสถานที่ รับงานซ่อม):** `http://localhost:8081` → login `1000000002` / `organizer1234`
4. **เว็บแท็บที่ 2 (เจ้าหน้าที่งานกิจกรรม ตรวจหลักฐาน):** login `1000000001` / `organizer1234`
5. **ให้คอมเด้งแจ้งเตือน:** ในเว็บแท็บ 1 และ 2 ไปแท็บ "แจ้งเตือน" → กด "เปิดแจ้งเตือนบนคอมนี้" → Chrome ถาม → อนุญาต · ปิด "ห้ามรบกวน / Focus assist" ของ Windows · (ถ้าไม่เปิด แจ้งเตือนยังเป็นแถบด้านบนของแอปเหมือนเดิม)
6. **(ถ้าอยากโชว์สมัครสมาชิก)** หน้าสมัคร เลือก "สมัครเป็น" เจ้าหน้าที่อาคาร/กิจกรรม หรือนักศึกษา → กรอก → เข้าแอปพร้อมแท็บตามบทบาททันที (ลองกรอกผิดให้เห็น validation ก่อน)
7. **บัญชีตัวอย่าง:** หน้าเข้าสู่ระบบมีปุ่ม นักศึกษา / เจ้าหน้าที่กิจกรรม / เจ้าหน้าที่อาคาร แตะแล้วเติมรหัสให้ · สมัครสมาชิกเลือกได้บทบาทเดียว
8. วางหน้าต่าง Chrome 2 บาน (แท็บ 1 / แท็บ 2) ซ้าย-ขวา ไม่ต้องสลับบัญชีระหว่างเดโม · อย่าปิดแท็บ (ต้อง login ใหม่) และอย่าใช้ "ทำสำเนาแท็บ"
9. สำรอง: ถ้า Wi-Fi ห้องสอบกั้นเครื่องคุยกัน ใช้ hotspot จากมือถือ
