# Build และ Release (สัปดาห์ 14)

## ตัวตนของแอป (app.json)

| ค่า | ตั้งไว้ | หมายเหตุ |
|---|---|---|
| name | KKUNK Today | ชื่อที่เห็นบนเครื่อง |
| scheme | `nktoday` | deep link เช่น `nktoday://activities/demo-hackathon` |
| version | 1.0.0 | รุ่นแรกของ KKUNK Today |
| android.package / ios.bundleIdentifier | `com.phop.nktoday` | ห้ามเปลี่ยนหลังขึ้น store |
| android.versionCode / ios.buildNumber | 1 | ต้องเพิ่มทุก build ที่ส่ง store (โปรไฟล์ production ตั้ง `autoIncrement`) |
| permissions | กล้อง, ตำแหน่งขณะใช้งาน, คลังรูป, แจ้งเตือน | ข้อความขอสิทธิ์บอกเหตุผลตรงกับพฤติกรรมจริง ไม่มีตำแหน่งเบื้องหลัง |

## EAS Build profiles (eas.json)

| profile | ใช้ทำอะไร | channel |
|---|---|---|
| development | dev client สำหรับนักพัฒนา | development |
| preview | APK แจกทดสอบภายใน (ผู้ตรวจติดตั้งได้เลย) | preview |
| production | ส่ง store, เพิ่มเลข build อัตโนมัติ | production |

```bash
npx eas-cli@latest login
npx eas-cli@latest build --profile preview --platform android
npx eas-cli@latest update --channel preview --message "แก้ข้อความ"
```

EAS Update (OTA) ใช้ได้เฉพาะการแก้ JavaScript/asset ถ้าเพิ่ม native module, เปลี่ยน permission หรือ app.json ต้อง build ใหม่
การนำเสนอวันสอบใช้ Expo Go ไม่ต้อง build

## Environment

- `EXPO_PUBLIC_API_URL` (ไม่บังคับ) ชี้ API ของแต่ละ environment ดู `.env.example` ปกติแอปหา IP ของ API ให้อัตโนมัติ
- ค่า `EXPO_PUBLIC_*` ถูกฝังใน bundle อ่านได้จากฝั่ง client **ห้ามใส่ความลับ**
- ใช้งานจริงควรให้หน่วยงานอนุมัติบทบาทเจ้าหน้าที่ (ตอนนี้เลือกเองตอนสมัคร)

## Release notes 1.0.0

- รวมกิจกรรม จิตอาสา และประกาศไว้ในแอปเดียว
- 2 บทบาท: นักศึกษา / เจ้าหน้าที่ (server ตรวจสิทธิ์ทุก request)
- กล่องแจ้งเตือนเดียว: อีกฝั่งทำอะไร → คนที่เกี่ยวข้องได้แจ้งเตือน แตะแล้วเปิดหน้าที่ถูกต้อง
- เตือนก่อนกิจกรรมตามเวลาที่ผู้ใช้เลือก
- กันแจ้งซ้ำในรัศมี 50 ม. ("เจอเหมือนกัน") และคิวงานเรียงตามความเร่งด่วน
- ชั่วโมงกิจกรรม/จิตอาสาจากการเข้าร่วมกิจกรรม (เช็กอินในแอป หรือเจ้าหน้าที่ตรวจใบเซ็นชื่อ)
- ออฟไลน์: cache + คิวแจ้งเรื่อง/เช็กอินใน SQLite ส่งเองเมื่อมีเน็ต

## ก่อนใช้งานจริง (production) ต้องทำเพิ่ม

- API ผ่าน HTTPS เท่านั้น
- ลบบัญชีตัวอย่างใน `server/seed.mjs`
- รูปใน `/uploads` เปลี่ยนเป็น signed URL หมดอายุ (ตอนนี้ป้องกันด้วยชื่อไฟล์ UUID ที่เดาไม่ได้)
- ยืนยันตัวตนนักศึกษากับระบบของมหาวิทยาลัยตอนสมัคร
- ย้ายข้อมูลจากไฟล์ JSON ไปฐานข้อมูลจริง
